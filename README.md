# 基于抹布湿度与擦拭轨迹的黑板粉笔灰残留分布模型

本项目为数学建模项目的开源代码与数据仓库。

## 项目简介
本项目针对教学中黑板“越擦越脏”及条纹分布现象，建立了一个基于质量守恒定律的粉笔灰动态分布数学模型。通过 OpenCV 图像灰度量化技术，将定性的黑板干净程度转化为定量的灰度残留值，从而拟合出抹布最佳湿度区间并提出了科学的值日策略。

## 核心功能
* **图像灰度量化**：自动提取黑板中心区域（ROI）的平均灰度值，客观量化残留粉尘反射率。
* **抗干扰裁剪**：自动剔除黑板边框及环境反光杂波。
* **参数拟合辅助**：为模型中的二次清洁效率曲线提供高精度的实验数据支撑。

## 运行环境
- Python 3.8+
- OpenCV-Python
- NumPy

## 使用说明
1. 将实验照片放入项目同一根目录下。
2. 运行 `process.py` 即可批量导出各工况下的残留量化亮度。
